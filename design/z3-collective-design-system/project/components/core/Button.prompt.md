Sticker-style pill button — the primary interactive element across Z3 surfaces.

```jsx
<Button>Add to cart</Button>
<Button variant="secondary" size="sm">Details</Button>
<Button accent="var(--z3-dragons)">Shop Dragons</Button>
```

Variants: `primary` (teal), `secondary` (white), `ink` (dark), `ghost` (quiet, no border). `accent` swaps the fill for a product-line color — use only within that line's context. Hover lifts (−1px, bigger shadow); press sinks (+2px, shadow gone).
